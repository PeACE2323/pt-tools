限速策略

在指定周期内，上传流量达到阈值时自动限速；进入新周期后自动解除。
至少需要保留一条策略。

通用设置

格式为 :端口。改动需要重启容器才会生效。
越小曲线越平滑，但对下载器 API 压力越大。建议 3s ~ 10s。
影响「自然日 / 自然周 / 自然月」的起算时刻，务必设置正确。

Webhook 推送

保存后立即生效。

配置文件（YAML）

适合需要批量修改或使用未在表单中暴露的高级选项的场景。
保存后会立即热重载，无需重启容器。修改 poll_interval、阈值、限速值都会即时生效。
阈值与限速均可使用友好写法：阈值如 500GiB、1.5TB；限速如 1MiB、512K，0 = 不限速。
周期 window 支持 24h / 7d / 30d；align 可选 day（自然日）、week、month、hour 或 rolling（滚动窗口）。
注意：表单与 YAML 是同一份配置，两边随时可以互相切换，改动都会同步。
