CD2 Webhook 可选功能

作用：CD2 的上传任务接口只提供目标路径，不提供源文件路径。 接入 Webhook 后，CD2 会在文件变化时主动推送真实源路径， 使规则匹配更准确，并让「取消后重新上传」能工作。
不配置也能用，只是源路径匹配会退化为用目标路径推断。

① 回调地址（本服务）
{{ webhookUrl }}

注意：这个地址是给 CD2 所在机器访问的， 如果 CD2 在另一个容器里，请把域名部分换成它能访问到的地址 （如宿主机 IP）。

② 在 CD2 里配置（三种方式任选其一）
方式 A（推荐）：打开 CD2 网页 → 右上角设置 → Webhook 页面 → 按下方模板填写并勾选启用。
方式 B：编辑 CD2 配置文件 config.toml （位于 CD2 的 /Config 目录），粘贴下方模板后重启 CD2。
方式 C：调用 CD2 的 gRPC 接口 GetWebhookConfigTemplate 获取模板再修改。
